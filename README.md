# Satyam Tyagi - Professional Portfolio

## Neon Dark Magical Theme with Watery Animations

This is a production-ready React portfolio website showcasing Satyam Tyagi's skills, projects, achievements, and contact information.

### Features
- Sidebar navigation with smooth page transitions
- Fully responsive (mobile, tablet, desktop)
- Neon dark theme with glowing borders and liquid hover effects
- Animated particle background and wave animations
- Projects page with YouTube video embeds (9 projects from given playlist)
- Detailed About page with tech stack, tools, certifications
- Achievements & hackathon wins section
- Contact form with neon styling

### Tech Stack
- React 18
- React Router DOM v6
- Framer Motion (animations)
- CSS Modules
- YouTube Embed API

### How to Run Locally

1. Ensure you have Node.js (v14+) installed.
2. Clone or download the project folder.
3. Open PowerShell/Terminal inside the `portfolio` folder.
4. Run the following commands:

```powershell
npm install
npm start
